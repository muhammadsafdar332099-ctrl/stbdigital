STB DIGITAL — GitHub Pages ready

Upload ALL files and folders from this ZIP to the ROOT of your GitHub repository. In Settings > Pages choose Deploy from branch > main > /(root).

Custom domain: in Settings > Pages enter stbdigital.site (after purchasing it). Set DNS records at your registrar according to current GitHub Pages documentation. Enable Enforce HTTPS once available.

IMPORTANT: Edit contact/index.html to add your real verified business email, address and phone before publishing. Review privacypolicy/index.html and adjust it to reflect your actual data practices.

Routes: /, /about/, /privacypolicy/, /contact/. GitHub Pages uses directory index files, so trailing slash routes are reliable.
